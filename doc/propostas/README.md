# Propostas

Cada ideia que chega pelo formulário do `d1.app.br` e vira planejamento tem uma
pasta aqui. Não é documentação do site: cada pasta descreve um projeto separado,
com repositório próprio.

| Proposta                                               | Recebida   | Estado                                   |
| ------------------------------------------------------ | ---------- | ---------------------------------------- |
| [causa-raiz-qualidade](causa-raiz-qualidade/README.md) | 2026-09-09 | Apresentação enviada, aguardando decisão |

## Antes de escrever qualquer proposta

[modelos-de-engajamento.md](modelos-de-engajamento.md) define os dois formatos de
trabalho: na casa do cliente, com o código dele, ou na sua casa, com o código
seu. A escolha é a primeira decisão de qualquer proposta, antes de escopo,
tecnologia e preço, e ela tem um quadrante proibido.
